# 网站表情素材

来源：用户提供的 1254 × 1254、5 列 × 4 行透明表情拼图。仅做独立裁切、边缘碎片清理、等比缩放和 WebP 压缩；未重绘人物，未使用外部图片服务。

| 文件 | 原图位置（从 1 开始） | 放置位置 | 动态效果 |
| --- | --- | --- | --- |
| hello.webp | 第 4 行第 2 列「你好」 | 首页桌面插画留白 | 轻摆；悬停/点按时摇摆打招呼 |
| work.webp | 第 1 行第 5 列「电脑工作」 | My Projects 标题旁 | 轻微点头；悬停/点按时上下律动 |
| cheer.webp | 第 1 行第 4 列「加油」 | 交互实验室标题旁 | 轻浮；悬停/点按时弹跳 |
| think.webp | 第 1 行第 3 列「思考」 | 资料问答标题旁 | 慢速歪头；悬停/点按时左右思考 |
| heart.webp | 第 4 行第 3 列「爱心」 | 联系区邮件入口旁 | 呼吸缩放；悬停/点按时双次心跳 |

- 每张图片是 256 × 320 的透明静态 WebP，使用 `object-fit: contain`，不裁切显示。动作来自 `stickers.css` 的 CSS 动画，不是逐帧人物动画。
- 首屏素材正常加载，其余图片懒加载。五张合计约 159 KiB。
- `stickers.js` 仅管理贴纸加载、视口状态和本地反馈，不调用外部 API，不改动项目/演示逻辑。
- 进入视口才播放，离屏或标签页隐藏时暂停；遵守系统 `prefers-reduced-motion` 与网站「动态效果」开关。
- 点按、Enter、Space 显示短句反馈；鼠标悬停只播放动作。无 JavaScript 时是静态图片；加载失败显示文字替代，不露出破图图标。
- 原图作者/授权详情未随图片提供；本目录不额外声明素材的再分发许可。
